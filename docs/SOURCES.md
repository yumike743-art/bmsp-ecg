# Sources and attribution

- Moody and Mark. MIT-BIH Arrhythmia Database v1.0.0, PhysioNet, 2005. The dataset describes its collection, data files, checksums, acquisition and Open Data Commons Attribution License v1.0. [Dataset](https://physionet.org/content/mitdb/1.0.0/) · [DOI](https://doi.org/10.13026/C2F305)
- MIT-BIH database directory. The collection describes modified Lead II, annotations and the shared subject in records 201 and 202. [Documentation](https://physionet.org/physiobank/database/html/mitdbdir/intro.htm)
- Moody and Mark. The impact of the MIT-BIH arrhythmia database. IEEE Engineering in Medicine and Biology Magazine, 2001. [DOI](https://doi.org/10.1109/51.932724)
- de Chazal, O’Dwyer and Reilly. Automatic classification of heartbeats using ECG morphology and heartbeat interval features. IEEE Transactions on Biomedical Engineering, 2004. The split was cross-checked against the conventional record lists, then modified to keep 201 and 202 together. [DOI](https://doi.org/10.1109/TBME.2004.827359) · [Record list](https://github.com/mondejar/ecg-classification/blob/master/python/load_MITBIH.py#L103)
- WFDB Python 4.3.1 provides signal decoding, reference annotation I/O and XQRS. [I/O documentation](https://wfdb.readthedocs.io/en/latest/io.html) · [Processing documentation](https://wfdb.readthedocs.io/en/latest/processing.html) · [WFDB annotation codes](https://www.physionet.org/physiotools/wpg/wpg_36.htm)
- SciPy provides the Butterworth design and forward–backward SOS filtering. Scikit-learn provides the median imputer, random forest and independent metric verification. [SciPy SOS filter](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html) · [Scikit-learn forest](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html)
- Moody, Muldrow and Mark. MIT-BIH Noise Stress Test Database, PhysioNet. It describes recorded classes of ECG artifacts discussed as a follow-up to the synthetic noise experiment. [Dataset](https://physionet.org/content/nstdb/1.0.0/)

Codex assisted with code, figures and editing. The visualization skill informed figure design and export. [Scientific Agent Skills](https://doi.org/10.48550/arXiv.2609.00065)
